## Decisions
- Rock UV contract: uv1 = blob offset (sim x, sim z) = UE local (X, Y); uv2 = (sim y = UE local Z, random), metres
  of the unit mesh (Blender rocks must write the same, Blender (x, y, z) -> UE (x, -y, z)).
- Wall / spike rise delay in vertex colour R (0 centre .. 1 outer), block random in G.
- Fighter-following items attach to the body mesh bone (absolute rotation/scale, geometry relative to the bone).
- Shared meshes uploaded once per pooled component; renderer keys uploads on (ptr, uid, version, topo).
- Flame / cone / funnel shapes animated in the material vertex shader from UVs (mesh = unit lathe).
- Transparent FX use AlphaComposite (premultiplied, Cover 0 = additive .. 1 = alpha) unlit; opaque: rock, lava
  strip, metal, vine, ground strip (lit).
- All logic in SIM space (metres, +Y up); UE glue converts once (FxUeConvert.h) and reverses triangle winding.
